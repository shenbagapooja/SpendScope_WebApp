# 💸 SpendScope – Expense Tracker & Analytics

SpendScope is a personal expense tracking web application built using Python and Flask. It helps users manage their daily expenses and understand their spending patterns through data visualization and analytics.

## ✨ Features

* 📊 **Dashboard** – View expense summaries and category-wise spending.
* ➕ **Add Expenses** – Record expenses with name, amount, category, and date.
* 📋 **View Expenses** – View saved expense records.
* 🗑️ **Delete Expenses** – Remove unwanted expense records.
* 📈 **Expense Analytics** – Analyze spending using charts and summaries.
* 🥧 **Data Visualization** – Visualize expenses by category.
* ⚙️ **Settings** – Access the settings page.
* 💾 **JSON Storage** – Store expense records locally.
